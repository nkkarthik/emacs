# ~/e

This file is NOT encrypted. Everything else that matters here is.

So it says as little as possible: only which contract to read. Repository
layout, machine names, capabilities, architecture and operational detail belong
in the encrypted contracts below, or in a task's own text — never here.

## Which contract to read

Read the ONE that matches you. Do not read both.

- working in `~/e/z` → `z/CLAUDE.md`
- working in `~/e/a` → `a/CLAUDE.md`

Executors receive no ambient contract at all. Everything needed for a piece of
work arrives in that task's own text, which is why a handoff must be complete
and self-contained.

## If neither matches you

Then you have no contract here, and the correct action is to stop and ask rather
than infer one.
